# 海戦バトルシップ隠し艦隊狩りゲーム

10×10グリッドに空母(5)・戦艦(4)・駆逐艦(3)・潜水艦(3)・哨戒艦(2)の5艦隻を配置し、CPUの艦隊を全滅させる海戦ゲームです。艦の手動配置またはランダム配置に対応し、CPUは確率ヒートマップAIを搭載（命中後は周辺を優先攻撃）します。命中は赤×、ミスは青○で表示され、ヒートマップ表示モードで攻撃の優先度を可視化できます。勝利数・敗北数はlocalStorageに保存されます。

## 使い方

艦をクリックして選択し、自軍海域をクリックして配置（回転ボタンで縦横切替）、またはランダムボタンで自動配置します。全艦配置後「戦闘開始」を押し、敵海域をクリックして攻撃してください。
